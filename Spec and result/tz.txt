Алгоритм работы метода:

По каждой строчке получаемой таблицы Z8PredictedDates входной структуры Z8Predictions запустить транзакцию IW22 по сообщениям ТОРО Z8PredictedDates.QMNUM для пакетного ввода значения Z8PredictedDates.LatestEndDate в поле сообщения ZZLATESTENDDATE.

Запускать только по тем сообщениям ТОРО, где это значение отличается от вводимой. Для этого предварительно проверить значение поля ZZLATESTENDDATE в таблице QMEL, где QMNUM = Z8PredictedDates.QMNUM.

1.4.3. Логирование. Транзакция SLG1.

Создать к объекту ZPM_APS подобъект IN_Z8_PRED_DAT «Получение даты заявки».

Для ошибок, предупреждений и при успешном завершении работы формировать логи.

DATA(lo_log) = NEW zcl_logger( i_log_name = 'ZPM_APS'
                                 i_sublog_name = 'IN_Z8_PRED_DAT' ).

Сообщения должны быть собраны в один блок лога.

Если поток был перезапущен из-за блокированных объектов, логи записывать только по этим сообщениям ТОРО (кроме п. 1.4.3.4., т.е. если объект продолжает быть блокированным не плодить логи).

1.4.3.1. Если ошибок нет после транзакции IW22, ls_syst-msgty = 'S', текст «Z8PredictedDates.QMNUM. Данные записаны».

1.4.3.2. Если QMEL-ZZLATESTENDDATE соответствовал Z8PredictedDates.LatestEndDate, ls_syst-msgty = 'W', текст «Z8PredictedDates.QMNUM. Данные идентичны».

1.4.3.3. Если возникла ошибка, отличная от блокировки объекта (IF line_exists( lt_messages[ msgid = 'IM' msgnr = 416 msgtyp = 'E'  ] ) не выдал положительный результат ), записать ошибку в лог ls_syst-msgty = 'E', текст «Z8PredictedDates.QMNUM. [  Ошибка из lt_messages где msgtyp = 'E' ] ».



1.4.3.4. Если ошибка связана с блокировкой (IF line_exists( lt_messages[ msgid = 'IM' msgnr = 416 msgtyp = 'E'  ] )), то необходимо в конце работы вернут на шину ошибку для повторной инициации потока.  Ошибка о блокировке записывается только один раз.

Соответственно, повторный алгоритм по потоку должен работать только по сообщениям ТОРО, которые были ранее блокированы. Для их анализа выбрать логи

mt_bal_log_db_messages = mo_dao->read_bal_log_from_db(
                               iv_subobject =  'ZPM_APS'
                               iv_object    =  'IN_Z8_PRED_DAT'
                               iv_begda     = CONV dats( ( sy-datum - 1 ) )  ).

 Оставить только те сообщения ТОРО, которые были ранее блокированы:

line_exists( mt_bal_log_db_messages[ msgid = 'IM' msgno = 416 msgty = 'E'  ] ) 

И по ним вызывать транзакцию IW22.

Гипотеза: использовать контекст логов для хранения номеров блокированных сообщений.
