# Адаптационное review: secondsky/sap-skills `sap-abap`

Дата review: 2026-08-04

## Решение

Внешний skill не устанавливается как обязательный контекст. Его рассматривают как источник идей и общих ABAP-справок; корпоративные правила СИБУР остаются единственным обязательным источником.

## Матрица решений

| Раздел внешнего skill | Решение | Причина |
| --- | --- | --- |
| Внутренние таблицы, `VALUE`, `OPTIONAL`, `DEFAULT` | Взять выборочно | Совместимо с ABAP 7.50 и полезно для безопасного доступа к строкам. |
| `line_exists` + повторный table expression | Исключить | Создаёт двойное чтение; в СИБУР используется один `READ TABLE ... ASSIGNING` либо `OPTIONAL`/`DEFAULT`. |
| Open SQL | Использовать только через правила СИБУР | Внешние примеры содержат `SELECT *` и не учитывают DAO. |
| ABAP Unit и исключения | Дополнить локальные правила | Добавлены проверки exception path и отсутствия persistence после ошибки. |
| RAP, CDS, EML, ABAP Cloud | Не включать по умолчанию | В этом репозитории CDS/AMDP допустимы только при прямом требовании ТЗ; RAP/Cloud — отдельный контекст. |
| Производительность | Считать справочным | Правила СИБУР по SQL, FAE, таблицам и памяти строже и имеют приоритет. |

## Принятые дополнения

1. Исправлен пример двойного чтения строки таблицы в `.agents/AGENTS.md`.
2. Добавлены правила обработки ожидаемых и технических исключений, а также проверки `IS BOUND`.
3. В `testing.md` добавлен набор unit-тестов на исключения и блокировку persistence после ошибки.

## Лицензирование

Исходный skill распространяется под GPL-3.0. В корпоративные документы не переносится его текст или примеры; изменения выше сформулированы самостоятельно и опираются на действующие правила СИБУР.
