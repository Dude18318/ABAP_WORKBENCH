# Сигнатуры Локальных и Глобальных Классов

В этой папке хранятся определения классов (ABAP Class Definitions), используемых в проекте.

## Как добавлять:
Создайте файл с расширением `.abap` (например, `zcl_logger.abap`) и вставьте туда `PUBLIC SECTION` определения класса.

### Пример формата:
```abap
CLASS zcl_logger DEFINITION PUBLIC CREATE PUBLIC.
  PUBLIC SECTION.
    METHODS constructor IMPORTING i_log_name TYPE balnobj OPTIONAL.
    METHODS add_syst_msg IMPORTING is_syst TYPE syst DEFAULT sy.
    METHODS add_bapiret IMPORTING im_ret TYPE bapiret2_t.
    METHODS display_log.
ENDCLASS.
```
