# Сигнатуры Функциональных Модулей

В этой папке хранятся описания сигнатур (интерфейсов) функциональных модулей (BAPI и RFC-модулей).

## Как добавлять:
Создайте текстовый файл `.txt` с именем ФМ (например, `z_check_authority.txt`).

### Пример формата:
```text
FUNCTION Z_CHECK_AUTHORITY.
*"----------------------------------------------------------------------
*"*"Локальный интерфейс:
*"  IMPORTING
*"     VALUE(IV_UNAME) TYPE  SY-UNAME
*"     VALUE(IV_ACTVT) TYPE  ACTIV_AUTH
*"  EXPORTING
*"     VALUE(EV_SUBRC) TYPE  SYSUBRC
*"  TABLES
*"      IT_PLANTS STRUCTURE  ZWERK_RANGE
*"----------------------------------------------------------------------
```
