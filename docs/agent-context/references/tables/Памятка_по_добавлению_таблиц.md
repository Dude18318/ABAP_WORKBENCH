# Описание Таблиц БД и Структур Словаря (DDIC)

В этой папке хранятся структуры кастомных таблиц и структур (Z-таблицы), необходимых для построения SQL-запросов и внутренней типизации.

## Как добавлять:
Создайте markdown-файл с расширением `.md` и именем таблицы в нижнем регистре (например, `ztsd_werkprd.md`).

### Пример формата:
```markdown
# Таблица ZTSD_WERKPRD (Сопоставление заводов)

| Поле    | Ключ | Элемент данных | Тип (длина) | Описание       |
|---------|------|----------------|-------------|----------------|
| MANDT   |  X   | MANDT          | CLNT (3)    | Мандант        |
| WERKS   |  X   | WERKS_D        | CHAR (4)    | Исходный завод |
| WERK_PL |      | WERKS_D        | CHAR (4)    | Целевой завод  |
```
