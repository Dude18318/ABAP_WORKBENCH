# Описание Глобальных Типов и Структур Данных

В этой папке хранятся определения типов (`TYPES`) и глобальных структур, необходимых для разработки, если они не описаны в коде локальных инклюдов или Z-таблицах.

## Как добавлять:
Создайте файл с расширением `.abap` (например, `global_types.abap`) и вставьте туда объявления `TYPES`.

### Пример формата:
```abap
TYPES:
  BEGIN OF ty_s_material_info,
    matnr TYPE matnr,
    maktx TYPE maktx,
    meins TYPE meins,
  END OF ty_s_material_info,
  
  ty_t_material_info TYPE STANDARD TABLE OF ty_s_material_info WITH DEFAULT KEY.
```
