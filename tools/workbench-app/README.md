# Workbench App

Локальный веб-интерфейс для работы с файлами и инструментами репозитория SIBUR ABAP Workbench.

## Запуск

Основной способ: запустите [Start SIBUR ABAP Workbench.cmd](../../Start%20SIBUR%20ABAP%20Workbench.cmd) из корня репозитория. Он сам поднимет сервер и откроет страницу.

Если батник не сработал, из этой директории выполните:

```bash
node server.js
```

После запуска приложение будет доступно по адресу:
`http://localhost:3000`
