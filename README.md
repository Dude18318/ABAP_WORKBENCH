# SIBUR ABAP Development Workbench

Данный репозиторий содержит материалы, исходный код, спецификации и тестовую среду для ABAP-разработок проекта SIBUR.

---

## 🚀 Быстрый запуск веб-интерфейса (Workbench App)

### Ключевые возможности Workbench App:
* 📁 **Редактор кода и файлов**: Удобное дерево файлов, просмотр и сохранение без сторонних IDE.
* 🔍 **Встроенный SIBUR ABAP Linter**: Проверка кода по правилам из `.agents/AGENTS.md` (выявление `SELECT` в циклах, отсутствия `@` в SQL, неоптимальных `FOR ALL ENTRIES`, длин методов > 30 символов и др.).
* 🔒 **ABAP Обфускатор**: Очистка кода от комментариев (`*`, `"`) и анонимизация локальных переменных (`lv_*`, `lt_*`, `ls_*`, `<fs_*>`) перед передачей кода во внешние системы.
* 🚀 **Генератор 10-файловых каркасов**: Автоматическая генерация архитектурного скелета отчета (MVC, DAO, View, ABAP Unit).

### Инструкция по запуску:
1. Основной способ: дважды кликните [Start SIBUR ABAP Workbench.cmd](Start%20SIBUR%20ABAP%20Workbench.cmd) в корне репозитория. Он запустит локальный сервер и откроет интерфейс в браузере.

2. Если батник не запустился, используйте ручной запуск. Перейдите в директорию приложения:
   ```bash
   cd tools/workbench-app
   ```
3. Запустите веб-сервер (без внешних зависимостей):
   ```bash
   node server.js
   ```
4. Перейдите в браузере по адресу: `http://localhost:3000`

## 📚 Документация и регламенты разработки

Все правила, инструкции и руководства расположены в папке `docs/agent-context/` и [.agents/AGENTS.md](.agents/AGENTS.md):

* **[Свод правил разработки (.agents/AGENTS.md)](.agents/AGENTS.md)** — обязательные правила по архитектуре (MVC, DAO), наименованию, оптимизации SQL/памяти и синтаксису ABAP 7.50.
* **[Playbooks для AI-агента](docs/agent-context/playbooks/README.md)** — контекстный роутинг для legacy-доработок, greenfield-отчетов, ТЗ и неизвестных Z-объектов.
* **[Паттерны архитектуры](docs/agent-context/architecture-patterns.md)** — разделение ответственности (Main/App, DAO, View, Event handling).
* **[Справочник HCM](docs/agent-context/hcm-development.md)** — специализированные правила для контура SAP HCM.
* **[Руководство по тестированию](docs/agent-context/testing.md)** — организация ABAP Unit тестов и mock-объектов DAO.
* **[Утилитарные классы](docs/agent-context/references/utility_classes/Памятка_по_утилитам.md)** — готовые переиспользуемые инструменты (`ZCL_LOGGER`, `ZCL_READ_MULTIPLE_TEXTS`, `ZCL_BDC` и др.).

## 📁 Структура репозитория

* `src/` — Исходный код ABAP-программ, инклюдов и классов.
* `tools/` — Вспомогательные утилиты и веб-интерфейс Workbench App.
* `docs/` — Справочная документация, спецификации типов/таблиц/классов и шаблоны.
* `dev_log/` — Журналы разработки, отчёты и пояснения по проведенным доработкам.
* `Spec and result/` — Спецификации (ТЗ) и документация по результатам.
